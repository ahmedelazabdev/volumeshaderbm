Why VolumeShader_BM Evaluates Real GPU Limits

Most 3D game tests measure rasterization pipelines, geometry transformation, and texture filtering bandwidth. In contrast, VolumeShader_BM executes a volumetric ray-marching algorithm on a single full-screen quad. Every individual pixel on your display evaluates an iterative 8th-order Mandelbulb distance function in real-time.

Mathematical Distance Estimator Loop

// Mandelbulb Distance Estimator (DE)
for (int i = 0; i < 6; i++) {
    r = length(z);
    if (r > 2.0) break;
    float theta = acos(z.z / r) + u_time * 0.15;
    float phi = atan(z.y, z.x) + u_time * 0.10;
    dr = pow(r, 7.0) * 8.0 * dr + 1.0;
    float zr = pow(r, 8.0);
    z = zr * vec3(sin(theta*8.0)*cos(phi*8.0), sin(theta*8.0)*sin(phi*8.0), cos(theta*8.0)) + pos;
}

Running dozens of iterative ray steps per pixel—each with trigonometric coordinate transforms—pushes GPU Arithmetic Logic Units (ALUs) to their computational peak, quickly uncovering hardware thermal throttling.

Frequently Asked Questions

Why did the benchmark start in Idle mode?

To keep the initial page render instantaneous and preserve your device's battery and CPU resources, the shader renders a single baseline frame first. Clicking Run Stress Test starts continuous ray-marching.

What causes the "Unsupported Canvas" error on some devices?

Hardware acceleration may be disabled in your browser settings, or your current webview environment has WebGL blocked.
